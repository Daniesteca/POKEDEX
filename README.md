# 🔍 Pokédex Web App

Una Pokédex interactiva desarrollada en **HTML, CSS y JavaScript** que consume datos desde la [PokéAPI](https://pokeapi.co/).  
Permite consultar Pokémon, ver sus estadísticas, tipos, imágenes y más, a través de una interfaz moderna y responsive.

---

## 🚀 Funcionalidades

- 🔎 Búsqueda de Pokémon por nombre o ID
- 📊 Visualización de estadísticas base con barras dinámicas
- 🖼️ Imágenes oficiales de cada Pokémon
- 🎨 Interfaz UI amigable y adaptada a dispositivos móviles
- ⚡ Carga rápida de datos usando Fetch API
- 🔥 Popup / Modal con información detallada del Pokémon
- 🧩 Render dinámico de tarjetas desde API
